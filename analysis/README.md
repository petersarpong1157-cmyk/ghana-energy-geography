# Empirical replication materials

**Project:** Renewable Energy Opportunity and the Geography of Infrastructure Disadvantage: Settlement-Level Evidence from Ghana  
**Authors:** Peter Sarpong (Independent Researcher) and Dora Konadu (University of Education, Winneba graduate, 2023; current affiliation not provided)

## What this archive contains
- **11 R scripts:** original Phase 1, 2, 2B, 2C, 3, 4, 5, 6, 7, 8, and 9 scripts under `scripts/`.
- **Numerical results:** uploaded result CSVs from Phases 6, 7, and 9 under `results/`.
- **Not included:** the original World Bank settlement CSV/GeoJSON, boundary ZIPs, Global Solar Atlas rasters, and variable-definition XLSX. Their provenance and redistribution terms should be confirmed before copying them into a public archive. Phase 9 large row-level geographic mismatch file is also omitted at present.

The scripts were developed sequentially and may require files generated by earlier phases. They are **archived original research scripts, not yet reworked into a portable one-command installer**.

## Getting started
1. Obtain the source dataset from [World Bank Ghana DRE Atlas](https://energydata.info/dataset/ghana-distributed-renewable-energy-dre). Follow its usage and citation terms.
2. Place `ghana_dre_atlas_settlements.csv`, `geofiles.zip`, and solar resource ZIP archives in the research working folder expected by the scripts.
3. Inspect package and path requirements before execution; the original scripts can install missing R packages and create `Phase*_Outputs` directories.
4. Run the scripts in sequence: Phase1, Phase2, Phase2B, Phase2C, Phase3, Phase4, Phase5, Phase6, Phase7, Phase8, Phase9.
5. Compare your outputs with the tables under `results/`. Different R/package versions and source data updates can affect results.

## Interpretation safeguards
- Modeled relative wealth may share satellite and connectivity-related data inputs with infrastructure indicators.
- Existing transmission-line proximity **is not verified electricity access**.
- Modeled long-run solar PV potential **is not actual installed electricity generation**.
- District administrative boundary validity dates and authoritative provenance are not independently confirmed.
- Residual spatial autocorrelation remains and Conley distance thresholds represent sensitivity choices.
- Results are associations, not estimates of causal impacts.

## Verification status
The principal region fixed-effects regression was independently reproduced in Python from the original CSV. Phase 6–7 results and selected Phase 9 tables were internally reconciled. **The complete end-to-end R and Conley/polygon pipeline has not been independently rerun.** Do not label this archive as fully independently reproduced.
